# Create 集成位置

Bridge 会在运行时按 Mod ID 和版本检测 Create。普通 Create 注册方块直接走通用 Registry、BlockState 和事务路径。

高级铁路、动力、物流和列车能力必须针对实际安装版本的 API 编译和实机验证后，才能由 `ModAdapter` 启用。不得猜测类名、方法或 NBT，也不得在能力不可用时伪造成功。

当前工程和 Gradle 缓存中没有目标整合包的 Create jar。官方 1.20.1 开发坐标当前指向 6.0.8-289，但用户整合包可能仍使用 0.5.1 或 6.0.x 的其他版本，因此本轮只启用版本无关的普通方块能力和运行时检测。
